# Habit Tracker — Capstone Project

**Track:** From Spec to Ship — Spec-Driven Development for the AI-Native SDLC
**Phase mapping:** this repo is where you'll do the Phase 1–5 Capstone milestones.

## What this is

A small habit-tracking app: log daily/weekly habits, calculate streaks, and handle the
edge cases that make streak logic genuinely tricky — timezones, daylight saving shifts,
and a "grace day" rule that forgives one missed day without breaking a streak.

It's intentionally small in *surface area* but real in *business-logic depth* — the
point isn't the CRUD, it's specifying the streak rule precisely enough that an AI agent
implements exactly what you meant, not what it guessed.

## Getting started (maps to your Capstone checklists)

1. **Phase 1** — read `specs/constitution.md` and `specs/features/*/spec.md`; these are
   the founding intent and backlog for this project.
2. **Phase 2** — follow the Claude Code + GitHub MCP setup checklist against *this* repo.
3. **Phase 3** — run `openspec init` here, then take `002-streak-tracking` through a full
   `propose → apply → archive` cycle (see `specs/features/002-streak-tracking/`).
4. **Phase 4** — wire up `.github/workflows/ci.yml`, add a security/lint gate, and fill in
   `docs/tooling-decision.md`.
5. **Phase 5** — ship `003-reminders` end-to-end, solo, as your final Capstone deliverable.
